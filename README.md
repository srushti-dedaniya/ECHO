# ECHO — The Living Social Universe
A spatial social fabric where humans align by shared emotional resonance instead of algorithmic popularity.

## Features
- **Ephemeral Moments** — No archives, no permanent footprints
- **Resonant Alignment** — Follow moments, not people
- **Spatial Universe** — Navigate by emotional frequency
- **Zero-Gravity Social** — No profiles, no metrics, no feeds

## Tech Stack
- React 18 + TypeScript
- Vite 5
- Tailwind CSS (custom design system)
- React Router 6

## Getting Started

```bash
npm install
npm run dev
```

## Project Structure
```
src/
├── components/     # Reusable UI components
├── pages/          # Page-level components
├── animations/     # Framer Motion / CSS animations
├── data/           # Static data & mock content
├── hooks/          # Custom React hooks
├── context/        # React Context providers
├── types/          # TypeScript type definitions
├── utils/          # Helper functions
└── styles/         # Global styles & CSS variables
```

## Design System
Custom Tailwind config with:
- Material 3 color tokens (dark mode)
- Space Grotesk / Plus Jakarta Sans / Space Mono fonts
- Custom spacing, border radius, typography scales
- Semantic color aliases (surface, primary, secondary, tertiary)
